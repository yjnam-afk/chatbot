- 감사: 다인 / 방법: **실브라우저(playwright·chromium) 1440×900·390×844에서 빈 상태 →
  작성(SLA·SLM 복합 25점) → 서랍 → 모바일 순으로 직접 조작·캡처·실측.** 코드 4파일
  (index.html/style.css/app.js/stage.js/progress.js/drawer.js) 전수 대조.
- 의도 기준: `docs/product-brief.md` §2 (화면 요소 4종 + 도크 제거 판정) + 발주자 레일
  재정의 지시(2026-07-17: "좌측 레일이 수험생이 궁금한 부분이야?").
- 판정 언어: **유지** / **수정**(의도에 복무하나 어긋남) / **제거**(복무 대상 없음) / **신설**.

## 0. 총평 — 3초 판독 테스트

첫 방문 화면은 "문제 넣는 큰 입력창 + 종이 한 장"까지는 읽힌다. 그러나 ①빈 용지가
**맨 괘선**이라 "기술사 답안지"가 아니라 공책으로 보이고(머리행·문제칸 없음), ②좌측
레일의 **대기 상태 진행 3단계**(레일 세로 676px 중 약 370px 점유)가 "이 앱의 관심사는
당신이 아니라 우리 파이프라인"이라고 말하고 있으며, ③헤더 배지가 "데모 모드 (라이브러리
적중은 실답안)"이라는 **개발팀 내부 사정**을 첫 화면 우상단에 노출한다. 결과 화면에서도
0.7초 만에 끝난 작업의 "완료 ✓" 카드 3장이 세션 내내 상주한다 — 발주자 지적("과정 구경은
무의미")이 실측으로 확인됨.

## 2. 상태 한 줄 사양 (진행 3단계의 대체물)

- 위치: 레일 최상단(탭 위), 높이 1줄(28px), 평시 `hidden`.
- 표시 조건과 문구(우선순위순):
  1. 오류: `⚠ 서버 오류 — 다시 시도해 주세요` (red 톤)
  2. 미적중: `미등록 토픽 — AI 예비 작성 중…` / 키 없으면 `미등록 토픽 — 서랍에서 등록 토픽을 확인하세요`
  3. 작성 1.5초 초과: `작성 중 — {현재 단계 캡션}` (기존 progress 이벤트 텍스트 재사용)
- 소멸: reply 도착 시 즉시 숨김(성공) 또는 안내 카드로 승계(미적중).
- 이벤트 매핑: progress.js의 AGENT2STEP·동결 로직은 캡션 공급용으로 유지, 스텝 DOM 렌더만 제거.
