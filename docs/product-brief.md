# 제품 기획서 — 기술사 답안지 자판기

작성: 누리(기획) · 2026-07-17 · 한 장 요약. 상세 근거는 각 스펙 문서(하단 링크) 참조.

## 1. 이 제품은 무엇인가

**기출 문제를 붙여넣으면, 3초 안에 강정배 방법론 포맷의 실물 답안지가 나오는 자판기.**

- **사용자**: 기술사 필기 수험생. 매일 손답안 연습을 하는 사람 — 연습할 "원본 답안지"가
  필요할 때마다 AI에게 새로 생성시키며 기다리는 것이 기존의 고통.
- **핵심 사용 여정 (30초 루프)**: 기출 문제 복사 → 입력창에 붙여넣기 → 답안지가
  화면에 채워짐(3초) → 인쇄 → 책상에서 손으로 베껴 쓰며 연습. 이 루프를 하루에도
  수십 번 반복할 수 있어야 한다.
- **속도의 비밀**: 매번 AI가 새로 쓰는 게 아니라, **토픽별로 미리 만들어 둔 답안
  부품(정의·개념도·구성요소표·비교표·두문자)** 을 문제에 맞게 골라 조립한다.
  그래서 등록된 토픽은 AI 호출 없이(= 인터넷 키 없이도) 즉시, 항상 같은 품질로 나온다.

## 2. 화면에 있는 것들 — 각각 왜 있는가

| 요소 | 존재 이유 (없으면 무엇이 안 되나) | 판정 |
|---|---|---|
| **문항 입력 영역** (상단, 여러 줄) | 실전 2교시 문제는 지문+가/나/다 여러 줄이다 — 통째로 붙여넣지 못하면 "기출 그대로 넣는다"는 제품 정의가 무너진다. | 유지 |
| **답안지 무대** (중앙, 실물 괘선 용지) | 이 제품의 결과물은 채팅 답변이 아니라 **인쇄할 원본**이다 — 화면에서 이미 답안지처럼 보이지 않으면 인쇄물을 신뢰할 수 없고, 연습 원본이 못 된다. | 유지 · 주인공 |
| **진행·분량 레일** (좌측 ①) | 진행 3단계는 "3초를 기다려도 되는가"의 신호, 분량 게이지는 방법론 합격 분량(1교시 1.2~1.4매 / 2교시 3~3.5매) 충족 여부의 확인 — 없으면 사용자가 결과물이 규격에 맞는지 직접 세어봐야 한다. | 유지 |
| **인쇄·내보내기 버튼** (레일 하단) | 여정의 종착지가 "인쇄"다 — 이 버튼이 묻혀 있으면 30초 루프가 화면에서 끝나버린다. | 유지 |
| **토픽 서랍** (좌측 ②) | 자판기에 "어떤 음료가 들어있는지" 보여주는 진열창 — 없으면 사용자는 무엇을 물어야 즉시 나오는지 알 수 없고, 미등록 토픽을 넣고 실망하는 경험만 반복된다. 두문자·정의 훑어보기는 자투리 암기 복습도 겸한다. | 유지 |
| **대화 도크** (우하단 접이식) | 존재 이유를 한 줄로 쓰지 못함 — 채팅 상담은 비범위(§3)이고, 경고·안내는 결과 메타 라인 한 줄로 충분하다. | **제거 대상** (시스템 알림 라인으로 대체 검토) |

원칙: 여기 없는 요소는 화면에 추가하지 않는다. 새 요소는 이 표에 "존재 이유 한 줄"을
먼저 쓸 수 있어야 들어온다.

## 3. 하지 않는 것 (Non-goals)

- **채팅 상담·공부 멘토링** — 이 제품은 대화 상대가 아니라 자판기다. 질문은 문제, 응답은 답안지.
- **학습 관리·암기 앱** — 진도·복습 주기·암기 카드 관리는 발주자가 이미 쓰는 도구가 있다. 토픽 서랍은 진열창까지만.
- **에이전트 쇼케이스** — 팀 캐릭터·말풍선·작업 연출은 제품 의도가 아니어서 제거했다. 진행 표시는 3단계 신호등으로 충분.
- **실시간 AI 생성 의존** — AI는 미등록 토픽의 예비 수단일 뿐. 등록 토픽은 키 없이, 항상 같은 품질로 나와야 한다.

## 4. 품질 기준 — "출고 가능"의 정의

- **방법론 전수 체크리스트(`methodology-checklist.md`) 100% 준수 = 출고 기준.**
  용지 규격(22줄 괘선·좌측 여백·"끝"·이하여백), 목차 구조, 정의·강조 서법, 표·개념도
  규칙까지 방법론 원문·실물 답안에서 역설계한 항목 전부이며, **추정으로 만든 규칙은 없다.**
- **견본 승인 프로세스**: 대표 토픽 1건의 1교시형·2교시형 견본 답안지를 발주자가
  실물과 대조해 승인 → 그 형식이 전 토픽의 기준이 된다. 견본 승인 전에는 전수 작업을
  시작하지 않는다(재작업 방지).
- 형식 검증은 사람이 아니라 기계가 한다: 조립 결과마다 형식 검사기가 체크리스트 항목을
  자동 대조하고, 위반은 화면에 경고로 드러난다.

  단락이 잡히는" 단계 — 실전 기출 24문 표본으로 설계했다.
