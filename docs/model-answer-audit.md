## 2. 중대 차이 상세 (로운 반영용 수정안)

### 2-1. MG-015 ISO 22301 — 구성요소 축이 모범답안 암기 축과 다름
- 모범 원문(MG_016_ISO22301.doc): 암기법 **"[조리계지운성개] 조직, 리더십, 계획수립, 지원, 운영, 성과평가, 개선"**,
  Ⅲ-가 주요내용 표 7행 = **조직의 상황/리더십/계획수립/지원/운영/성과관리/개선** (ISO 22301 7조항).
  "키워드(암기): PDCA, **구성요소는 암기 필요**" — 7조항이 시험 정답 축.
- 현행: 두문자 "피디씨에이", components 4행(조직 상황/기획/운영/평가·개선)으로 7조항 압축.
- 수정안: ① mnemonic을 `조리계지운성개(조직·리더십·계획·지원·운영·성과·개선)` 주축 + PDCA 병기로 교체.
  ② components를 7조항 기반으로 재작성 — r2 4행 상한은 rowspan 묶음(P:조직상황·리더십·계획수립·지원 /
  D:운영 / C:성과평가 / A:개선)으로 해소하면 PDCA 매핑도 함께 보여줄 수 있음(모범 Ⅱ표+Ⅲ표 통합 효과).

### 2-2. MG-047 ISP — 모범답안의 두 핵심 표가 부품에 없음
- 모범 원문(MG_054_ISP.docx): ② Ⅱ-나 **수행 내용 대형 3단표(활동|작업|세부내용)** — 환경분석(경영현황·법령제도·IT환경) →
  현황분석(업무·정보시스템·벤치마킹·차이분석·이슈통합) → 정보화 비전전략 → 목표모델설계(TO-BE 5종) →
  통합이행계획(구축계획·총사업비(FP/장비/운영유지 5년)·효과분석) → 사업계획서·RFP.
  ③ Ⅲ **검토 구성항목** — 사업타당성(필요성·시급성·중복성)/실현가능성(사업추진여건·기술적정성)/규모적정성(SW대가산정·HW규모산정).
  암기법 5종: 환형정목통, **사실규, 필시중, 사기, 대규** — 기출(123회 관리 2-6 등)이 검토항목을 직접 물음.
- 현행: Ⅱ가 절차 개념도만(표 없음), 검토 구성항목 부품 전무, 두문자 환형정목통 단독.
- 수정안: ① components에 절차 5단계×작업 요지(rowspan)로 수행내용 표 신설(셀은 손글씨 밀도 상한 준수해 요지만).
  ② exam_points 또는 전용 부품으로 검토 구성항목 3분야 7항목 표 추가(요구 주도 조립의 "검토/구성항목" 요구에 배정).
  ③ mnemonic expansion에 사실규(사업타당성·실현가능성·규모적정성)·필시중 병기.

### 2-3. MG-166 전자정부 성과 측정지표 — 공식 지표 축·판정 결과 불일치
- 모범(손답안 OCR, SW_정보시스템운영성과평가.pdf; 전자정부법 68조·행안부 지침 기반):
  비용 기준 = **운영 적정성/유지보수 용이성/비용 효율성**, 업무 기준 = **사용 편의성/업무 적합성/성과 달성도**,
  판정 = 점수(3점 기준) 매트릭스 → **유지/고도화/재개발/폐기** 4결과. 대상 = 구축 후 1년 이상 공공 시스템.
  기대효과 = 정부(효율)·국민(만족)·기업(사업).
- 현행: components가 운영비용/TCO/업무효율/활용도 — 공식 지표 명칭과 다름. 정의·부품에 "유지·폐기"만 있고
  고도화·재개발 누락, "구축 후 1년 이상" 대상 기준 누락.
- 수정안: ① components를 공식 6지표로 교체(비용측면 rowspan 3행 + 업무측면 rowspan 3행 — 손글씨 밀도 내 요지).
  ② usage 또는 features에 판정 매트릭스(비용·업무 점수 조합 → 유지/고도화/재개발/폐기) 추가.
  ③ definition_long에 "전자정부법 68조, 구축 후 1년 이상" 어절 반영. ④ 두문자 "비업"에 지표 6종 풀이 병기.
